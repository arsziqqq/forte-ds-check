# Тексты для публикации Forte DS Check

## Tagline

Проверка и автоисправление макетов по токенам, стилям и компонентам ДС Forte

## Description

Проверяет выделенные экраны на соответствие дизайн-системе проекта и помогает сразу всё исправить.

Что ловит:
— цвета, отступы, радиусы и эффекты без токенов;
— текст без текстового стиля;
— переменные и стили из чужих библиотек (сверка по ключу коллекции);
— компоненты не из ДС, локальные и отвязанные (detach);
— переменные не по назначению (например, отступ в радиусе);
— устаревшую версию библиотеки;
— слои с именами по умолчанию (опция, включается в профиле).

Автоисправление в один клик:
— отступы и радиусы → переменные ДС; если точного значения нет — ближайшее в пределах 4 px (17 → Space/4x = 16);
— чужие переменные отступов и цветов (например, Spacing semantic) → свои токены из ДС;
— текст без стиля или с чужим стилем → текстовый стиль ДС по начертанию и размеру (Regular 14 → Caption/Caption2);
— HEX-цвета → цветовые токены по скоупу (Border/* для обводки, Text/* для текста, Background/* для фона), близкие оттенки — к ближайшему;
— если подходит несколько токенов с одним значением, можно выбрать нужный из списка.
Исправления к ближайшему значению помечены — их стоит проверить глазами.

Для каждого проекта и платформы создаётся профиль: файл токенов, файл ДС, библиотека иконок — сколько нужно источников. Внутри инстансов проверяются только overrides дизайнера, содержимое слотов — полностью.

## Release notes для «Publish new version»

Автоисправления: отступы и радиусы привязываются к переменным ДС (если точного значения нет — к ближайшему в пределах 4 px), текст — к текстовым стилям ДС по начертанию и размеру, цвета — к токенам по назначению (Border/Text/Background), чужие переменные — к своим. Если подходит несколько токенов, их можно выбрать из списка. Проверяется только выделение, с превью выделенного экрана. Добавлено опциональное правило нейминга слоёв.
